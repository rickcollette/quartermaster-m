# Atari ATASCII Complete Reference Kit

A practical collection for Atari 8-bit terminal, BBS, graphics, font, emulator,
and conversion work.

## Start here

1. `docs/ATASCII_REFERENCE.md`
2. `charts/ascii_atascii_table.pdf`
3. `charts/gury_character_chart_1.jpg` through `_6.jpg`
4. `data/atascii_screen_code_map.csv`
5. `data/atascii_control_codes.csv`
6. `docs/ATASCII_ART_AND_BBS.md`
7. `tools/atascii_convert.py`
8. `examples/`

ATASCII, keyboard codes, and internal screen codes are different code spaces.
ATASCII is used for interchange and CIO text I/O. Internal codes index glyphs
in screen memory. Keyboard codes are input-handler values.
